# Cyber Hack: Crack the Code

A responsive, zero-build cybersecurity deduction game. It uses plain HTML, CSS, and JavaScript; best scores are saved locally in the browser.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Publish with GitHub Pages

1. Create a repository named `cyber-hack-game` and place this folder's contents at the repository root.
2. Push the `main` branch. The included workflow builds the Pages artifact and deploys the static site.
3. In the repository's **Settings → Pages**, select **GitHub Actions** as the build and deployment source if it is not already selected.
4. Open the Pages URL after the deployment workflow succeeds.

No server, API keys, build step, or JavaScript libraries are required.
